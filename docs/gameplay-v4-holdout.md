# 正式留出样本

本文件是正式留出样本单集，totalGames = 18000。6 策略 × 3 难度 × 1000 种子 = 18000，是一集，不是 36000，也不是 C1。另一集单独成文件。

模式 holdout。规则版本 0.4，价格簿 0.2。耗时 252.0 秒。

涨跌分位的 n 是本难度 1000 条价格路径的观测。六策略重复同一条路径，n 不乘 6。
官方份额是各局各商品正已实现利润求和。负贡献单独列出。legacyMeanNetShares 是旧的跨局均值口径，会抵消同商品负局。docs/gameplay-v4-c1.md 的名表 55.1% 只属于旧口径。

## 参数

- Engine.visible 的公开字段，加商品资料 role、lowRef、basePrice、size、category。不读 snapshot、activeEvents、onStreak、absence、rng、trend，也不读下一周价格。
- 收益 = (H.channelNet(visible, id, qty) - cost) / cost。不用 price * 0.99。
- 当前 listing 含该 id，空间够，qty * price + fee <= min(cash, budget)。dispatch 失败就抛出，不吞掉。
- 每周没有住房且现金够本局 priceBook 最低档，就买最低档。第 52 周这次检查发生在清仓之前。非 idle 再按当前渠道卖光持仓，然后买现金加现房价值够到的最高档。idle 不清仓。成功只看实际买到的住房 id。
- 沿用旧模拟：非 idle、周数 < 38、占用 >= 容量 80%、现金 > 升级差价的 2 倍，就升一档。随机策略在独立政策随机数 < 0.25 时才升。
- 每次成功 dispatch 之后记录现金。年内最低现金 < 起步现金的 10%，记 everLowCash。
- 终局现金 < 起步现金的 10%，记 terminalLowCash。不与 everLowCash 混用。前一版表头「极低现金」实际是终局口径，且 minCash 只在周初读取。
- 年内最低现金 <= 0。最低现金含买入、租仓和买房之后。
- 当周占用 >= 容量 95%，且现金够买一件当前在售、但剩余空间放不下的商品。组比率是这种周数 >= 4 的局占比。
- visible 头条存在且 id 不是 move。统计该周全部 12 个商品，含未受影响商品。不是“只有受影响商品”。
- 没有新事件头条。持续项和结构项仍可能在作用，不叫无事件背景。统计全部 12 个商品。
- 只统计冲击首周、本周效果命中的商品。事后从 H.prices 返回值连接，决策函数不读它。
- 同一难度 30 条价格路径被 6 个策略重复。可以对照策略，不能把观测数乘 6 当成独立样本。
- H.prices 返回本次诊断。raw !== clamped 才计钳制。贴界且 raw 未越出不算。persistCap 触发单独计数，不并进钳制。诊断在 validate 成功并提交后才累加，restore 重置，拒绝的 next 不增加。
- 同一种子、同一买卖和住房规则。仓储函数仍抽随机数以保持随机策略的序列，但不提交升级。只诊断共同 80% 租仓政策，不是第七个正式策略。
- 保守：在售，且 role 为 daily 或 lowRef，且 price/base < 0.92。仓位 0.4。卖出收益 >= 0.08，或价格/参考价 >= 1.03，或收益 < -0.18。
- 随机：卖出概率 0.5，买入概率 0.5，仓位 0.2 到 0.8。H.seed("policy:"+seed+":"+strategy)，不碰引擎四个随机流。
- 追涨：周涨幅 > 1.025 且价格/参考价 < 1.55，仓位 0.8。卖出：价格 < 上期 × 0.985，或收益 >= 0.2，或收益 < -0.15。
- 价值：价格/参考价 < 0.84，仓位 0.8。卖出收益 >= 0.18，或价格/参考价 >= 1.03，或收益 < -0.3。未上架时，卖出能腾出空间、并且 channelNet 加现有现金够买那件被挡住的折价商品的最少数量。同一周按卖出后的新 visible 再比较。
- 事件感知：缺货或退出持仓卖出。新闻 changeBps <= -800 也卖。收益 < -0.12 也卖。买入本周 fresh 新闻且 changeBps >= 800 的在售商品，仓位 0.6。
- 不交易：不买卖商品。共同住房规则仍然生效。

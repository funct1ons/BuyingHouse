# 0.13 / save12 当前规则

规则版本为 0.13，活跃存档键为 `homeyear.save.v12`。本版允许贷款购房，并在年末以现金优先偿债，必要时拍卖住房。记账单位仍为分，1 元 = 100 分。

## 贷款购房

- 经营期间，有未还贷款也可以买房或升级住房，仍需足够现金支付房款或升级差价。
- 升级仍按当前住房当周市价抵扣，正常经营期间不能降档。
- 信用社仍为 500 / 1000 / 2000 / 3000 元四档，一次一笔，全部还清后才能再借。
- 周息仍为 1.5% 单利，按分向上取整；跨周计息，结束本年时仍有本金则再计最后一周利息。
- 经营期间还款仍由玩家操作；年末结算会自动偿债。

## 年末结算顺序

第 52 周仍可交易和主动还款。点击“结束本年”并确认后：

1. 仍有本金时补计一次末周利息。
2. 先用现有现金偿还利息，再偿还本金。
3. 现金足够清债时保留住房，直接完成年度结算。
4. 现金不足清债且名下有住房时，按第 52 周住房市价拍卖，不收额外手续费；拍卖收入继续先息后本偿债。
5. 发生拍卖后进入一次重新置业阶段。债务已清且余款足够时可选择任意可负担住房，包括原住房或较低档住房；买下即完成结算，也可以放弃并结算。
6. 拍卖收入仍不足时现金保持非负，剩余债务记录到年度结算；此时不能重新购房，只能放弃并结算。

无住房可拍卖时，现金偿债后直接结算，剩余债务保留。库存始终不自动出售，因此想用库存所得偿债的玩家应在结束本年前卖出。

拍卖后的重新置业阶段不允许交易、借款、还款、刮奖、扩仓或推进周数，也不会再次计息。可以保存、导出及重新载入该阶段，再完成买房或放弃。重复结算不会重复偿债、拍卖或计息。

## 其他规则

沿用 [0.12 的价格簿及房价规则](gameplay-rules-0.12.md)。三种难度、商品行情、传闻、黑天鹅、手续费、回收折价、仓储、贷款额度与利率、彩票奖金与概率均沿用现有配置。

年度置业历史保留拍卖前的购买记录；最终住房以结算后实际持有的住房为准。参考资产与扣除债务后的资产分别展示。机制验证通过不等于已经重新完成玩法平衡评估。

## 存档和版本

新增结算阶段与偿债记录，因此升级为 v12。v1–v11 原键原文保留，可在设置中导出；不自动迁移、不覆盖、不删除，更新后需开始新游戏。损坏或未来版本的当前档仍进入隔离。设置与里程碑使用原来的独立存储键。

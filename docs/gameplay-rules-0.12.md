# 0.12 / save11 当前规则

当前开发协议为规则 0.12，活跃存档键为 `homeyear.save.v11`。旧 v1–v10 原文保留但不迁移。价格簿 `0.4`。周涨仍是 `101^(week−1)/100^(week−1)`，手续费仍 1%，仓储、黑天鹅、商品、贷款、刮刮乐不变。0.11 文档仍是上一版合同。本文只记本版房价重标定和引导。

记账单位仍是分。1 元 = 100 分。

## 为什么改城里底价、不改周涨

内测反馈标准难度偏难，好一点的房子很难买上。200 种子、0.11 标准 + 价值脚本：任意买房 37%，公寓及以上 14.5%，两居及以上 3.5%。设计里第一套房应是普通阶段胜利；脚本捡漏都难买两居，真人更难。

「好一点」的目标档是舒适两居。公寓应更常见，两居是认真玩一年的典型落地；城市住宅 / 理想之家仍要好判断加运气；小洋楼及以远保持极稀。

房价每周 1% 保留。年底一次性付两居全款仍然贵（底价 × 约 1.66）。两居要常见，主路径是年中先买单间或公寓（锁进涨幅，按当周市价抵扣），再继续做生意，年末升到两居。只降价、不讲先上车，人仍会囤现金等到第 52 周。

## 引导

- 教程第 4 步：房价每周大约 +1%；现金够了先买钥匙，留一点周转；升档按当周市价抵扣；库存市值付不了房款。
- 售楼处传单：本周价，外加「若等到第 52 周，本日口径约 xx」。用当前 `housingLog` 的 `houseAt` / `houseQuote(..., 52)`，不另造预测。
- 现金第一次够单间、还没住房、没有贷款：一次轻提示。会话内按种子记，不进存档，不每周重复。
- 单间结局「有了自己的门」。
- 有贷款时售楼处已关门：按钮旁与关门文案补「年底买房要先还清」。
- 「更远处」说明保留。城里三档加「先住进来，再换大的」。

# 0.8 / save7 当前规则

当前开发协议为规则 0.8，活跃存档键为 `homeyear.save.v7`。旧 v1–v6 原文保留但不迁移。商品黑天鹅、手续费、仓储标价、52 周、难度系数和商品价格不变。价格簿 `0.2` 保持原样。新局使用价格簿 `0.3`。本文只记本版合同，新房价没有平衡结论。

住房在原五档之后增加四档。标准难度第 1 周标价（分）：市中心小洋楼 3600000、首都四合院 6200000、独立海岛 10800000、火星定居舱 20000000。轻松为 `round(标准×0.8)`，挑战为 `round(标准×1.25)`。旧五套和仓储三难度原样抄自 `0.2`。

房价一次算完，不逐周滚整数。市价 = 半分进一(底价 × 101^(周−1) / 100^(周−1) × 已发生且冲击周 ≤ 该周的分子连乘 / 分母连乘)。整数式是 `(base * num + den/2) / den`。第 1 周无增长、无冲击，等于底价。买房或升档应付 = 目标当周市价 − 已有房当周市价（无房为 0）。不能降档或同档。累计实付写入 `houseBasis`。现金恒等式减去 `houseBasis`，不减去当周市价。

住房冲击只用 `rng.housing`。概率 0.12，第 6–46 周，相邻至少隔 8 周，最多 3 次。不合格不消耗随机数。未命中不再抽事件。四个事件不进入 `H.events`：`housing_stimulus` 108/100、`housing_first` 105/100、`housing_default` 92/100、`housing_index` 94/100。游戏百分比是虚构映射。违约条只记预期冲击，不是投资建议，不引导断供。

本周若有住房冲击，新闻追加一条 `kind: housing`，`productId` 为 null，涨跌基点用单间当周口径。它不是商品头条，不占快报三行。

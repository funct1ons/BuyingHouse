# 0.11 / save10 当前规则

当前开发协议为规则 0.11，活跃存档键为 `homeyear.save.v10`。旧 v1–v9 原文保留但不迁移。房价、手续费、黑天鹅、商品、仓储都不变。价格簿 `0.3` 不变。0.10 文档仍是上一版合同。本文只记本版新增的两件事。没有重跑平衡模拟，不能当作已经平衡。

记账单位仍是分。1 元 = 100 分。

## 贷款（街区信用社）

档位 500 / 1000 / 2000 / 3000 元，即 50000 / 100000 / 200000 / 300000 分。一次一笔。还清本金和利息才能再借。

周息 1.5%，单利。一周利息 = `ceil(本金分 * 15 / 1000)`，单位分。例：本金 50000 分，一周为 750 分。利息不滚入本金。不自动扣款。

跨周按「下一周」计一周，基数是当时本金。第 52 周结束本年时，如果本金还在，再计一周。放出当时不计息。同一周内借出并还清，利息为 0。

还款先利息后本金。还 500 元（50000 分）。未还本金加利息不足 500 元，或现金不够 500 元，整笔拒绝。

有未还本金或利息时，售楼处拒绝接待。不能买房，也不能升档。已买的房子还在。还清的同一周可以再买。顶栏目标房价仍公开显示。

账面净资产仍是现金 + 参考市值 + 住房市价。不扣贷款。界面另显示未还贷款。

## 刮刮乐

30 元一张（3000 分）。不限次数。现金不够或年份结束才拒绝。

版面 3×3。每张按权重抽一种图案，该图案出现 3 次，奖金取该图案。奖金可以是 0。格子位置不改变奖金。当场扣票价，再加上奖金。票价和奖金分开记账。

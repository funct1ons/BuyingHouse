# 内测现行规则 0.6 / 存档 v5

本轮按内测反馈更新日历与信息展示，不改变黑天鹅概率、幅度、冷却、费用、价格上下界、住房仓储标价或策略。`gameplay-rules-0.5.md`、`save-v4.md`、旧 540 局诊断及 0.4 正式样本均为历史；不能作为 0.6 日历经济的平衡证据。本轮不执行正式模拟。

## 日历与经营时间

- 经营 `week` 仍为 1…52；第52周仍可交易、卖货、购房，结束须确认，无第53周、不自动清仓。
- `calendarStartWeek = seed(seedText + ':calendar') % 52 + 1`，均为安全整数1…52。它独立派生，不消耗 market/events/visual/listing 四条既有随机流。
- `calendarWeek = (calendarStartWeek + week - 2) % 52 + 1`。冬/春/夏/秋各13周循环；初局、环境、季节价格余弦、夏季热浪候选及历史热浪日志校验、画面附件都使用同一日历。
- 保存必须带与种子对应的 `calendarStartWeek`；公开 `visible()` 增加该起点、当前 `calendarWeek` 与 `season`，不暴露RNG、未来事件或调度候选。
- 同版本同种子同动作可重现；恢复/导入后未来与未中断路径一致。不承诺与0.5的季节及经济路径一致。

## 进度条与末周

横向纸本进度条替代圆环/日历小牌：playing 已完成 `week-1` /52；ended 为52/52并显示“已结算”。文本显示经营周数、本季剩余 `13 - ((calendarWeek-1)%13)` 周（含本周）及下一季。本季剩余不因经营年底截断。

第50/51/52周持续醒目提示“含本周还可经营3/2/1周”，成功推进到对应周一次toast；恢复或导入仅显示持续提示，不重播推进toast。第52周明确仍可交易，结束须确认。结算后不再显示未结算警告。

## 黑天鹅事件与来源

新发生事件仅在成功 `next` 后，`fresh headline` 且 `swanLog` 有本周匹配记录时，复用原dialog打开“黑天鹅事件 · 已发生”。初局、恢复、导入、设置变化、同周交易、普通消息、ongoing不自动重播。快报“现实原型 / 事件详情”可手动重开，包括ongoing。

弹窗包含原创标题、经营发生周、事实发生提示、每个effects商品实际当前 `changeBps`、在售/回收渠道及持仓净額。明确实际涨跌包含噪声/边界，不等于配置首冲或新闻价格；持续中枢不重复首冲，到期不保证反弹。查看商品先关闭事件窗再打开交易窗，禁止嵌套modal；Esc/Tab/ShiftTab使用原键盘基础设施，关闭事件/随后商品窗返回逻辑下一周入口，不提交操作。

七条来源保存在 `H.swanOrigins`，摘要离线内置，不fetch。来源事实与游戏映射分区；外链使用`target=_blank rel="noopener noreferrer"`。“黑天鹅”是游戏类别，不宣称每条现实原型都严格不可预期。权威来源与限制来自 `gameplay-ui-and-black-swan-plan.md` §§10–12及本轮核实：IMO、Reuters/Kitco、USDA ERS（两种独立蛋品原型）、WMO、WTO、WHO。股票不等于显卡零售价，算法效率未被本文证实；需求下降/病例暂停不等于产能恢复或加急到货；贸易预测不是全年结果；游戏商品方向/幅度都是原创。

## 存档边界

唯一活跃键`homeyear.save.v5`，规则0.6/save5。当前档严格结构、资金/费用账本、日历种子一致性校验。设置/关注/音量键不变。

不支持旧v4/v3/v2/v1迁移、继续或导入，不显示迁移入口。旧键原文保留，不将旧档叫作损坏新档；没有v5但有旧键时提示“内测规则更新，旧档不兼容，请开始新游戏”，允许正常开始并保存v5。旧导入拒绝且不写备份/原键/新档。

损坏或未来v5仍隔离，自动保存不覆盖；可导出原文，只有明确`replaceDamaged:true`恢复动作可覆盖。当前档导入只替换内存，保存/自动保存才持久化。保存失败是经济已提交未保存，不能重做交易或重抽事件。历史冻结v2/v3上下文与历史转换代码保留，但0.6迁移入口明确拒绝。

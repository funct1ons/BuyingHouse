# 0.9 / save8 当前规则

当前开发协议为规则 0.9，活跃存档键为 `homeyear.save.v8`。旧 v1–v7 原文保留但不迁移。房价每周 1%、住房冲击、手续费、仓储标价、52 周、难度系数、商品基准价和普通市场事件概率不变。价格簿 `0.2` 保持原样。新局仍使用价格簿 `0.3`。本文只记本版合同。新的黑天鹅出现频率没有做过平衡模拟，不能当作已经平衡。

商品黑天鹅仍走 `rng.events`，不占用 `rng.housing`。窗口仍是第 4–50 周。概率从 0.16 改为 0.42，相邻至少隔 4 周，一年最多 8 次。每种事件一年最多一次。主商品本周未上架、季节不符，或与非结构性普通事件重叠时，该周不抽这只事件；没有候选时不消耗这次黑天鹅随机数。原有七个事件的效果表不改。

新增八个事件，涨跌都有，彼此不组成固定先后：

- `swan_export`：先进芯片出口管制。显卡、手机上涨。原型为 2022-10-13《联邦公报》临时最终规则。
- `swan_redsea`：红海航运遇袭后改道。手机、名表上涨。原型为 2024-01-10 联合国新闻所载安理会决议。不描写伤亡。
- `swan_gas`：只在冬季。羽绒服上涨。原型为 2022-12-12 IEA 关于欧盟天然气缺口的报告。游戏涨幅不是报告里的立方米数。
- `swan_nino`：水果、大米上涨。原型为 2023-07-04 WMO 宣布厄尔尼诺开始。
- `swan_grain`：大米、猪肉下跌。原型为 2022-07-22 黑海粮食出口协议。不是任何短缺事件的定时后续。
- `swan_meat`：只抬猪肉。原型为 FAO 2022 年 3 月食品价格指数稿（页面 CreatedOn 2022-04-08）。游戏幅度不是指数里的 4.8%，大米不跟着动。
- `swan_rates`：名表、藏品下跌。原型为 2022-09-21 美联储 FOMC 声明，目标区间至 3%–3.25%。不是利率点数，也不是预测。
- `swan_bank`：藏品、显卡下跌。藏品首冲停在 −9500 基点以内，避免一次冲击把价格打到零。原型为 2023-03-10 FDIC 接管硅谷银行受保存款人。不是买卖建议。

弹窗里的百分比来自当周成交价。新闻页上的实测变化不会被写成游戏自己的涨跌。

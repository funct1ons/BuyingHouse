## 覆盖的边界

- 同周借款购房及带债升级。
- 三难度下无现金、部分利息、恰好利息、部分本金、恰好清债和有余款。
- 现金足够保留住房；现金不足按末周市价拍卖且无费用。
- 回购只能执行购房或放弃，重复结束不重复计息或拍卖。
- 拍卖后刷新继续、导出导入恢复，重买或放弃后正确展示年度账单。
- 库存不自动出售、无房时欠款保留、现金不为负。
- 结算字段、拍卖价和购房历史篡改拒绝。
- v11 原文保留并优先导出，拒绝旧档导入且不改变当前内存与本地档。

当前生产房价下，最低末周住房价值高于最大全年欠款。“拍卖后仍欠债”使用仅存在于测试内的低价报价验证偿债函数，同时验证未清债时不能重新购房。

## 范围与限制

此次没有重跑大规模经济平衡模拟；通过机制和回归测试不代表玩家胜率已重新评估。旧档导出检查了下载 Blob 的逐字内容，未验证操作系统下载落盘。未发布到 GitHub Pages。

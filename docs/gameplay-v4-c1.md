# C1 小样本诊断

6 策略 × 3 难度 × 30 主种子 = 540 局。未使用留出种子，未改房价，不是正式 36000 局。

规则版本 0.4，价格簿 0.2。耗时 6.8 秒。

## 待审批参数

- 信息边界：Engine.visible 的公开字段，加商品资料 role、lowRef、basePrice、size、category。不读 snapshot、activeEvents、onStreak、absence、rng、trend，也不读下一周价格。
- 卖出收益：收益 = (H.channelNet(visible, id, qty) - cost) / cost。不用 price * 0.99。
- 买入检查：当前 listing 含该 id，空间够，qty * price + fee <= min(cash, budget)。dispatch 失败就抛出，不吞掉。
- 住房：每周没有住房且现金够本局 priceBook 最低档，就买最低档。第 52 周这次检查发生在清仓之前。非 idle 再按当前渠道卖光持仓，然后买现金加现房价值够到的最高档。idle 不清仓。成功只看实际买到的住房 id。
- 仓储：沿用旧模拟：非 idle、周数 < 38、占用 >= 容量 80%、现金 > 升级差价的 2 倍，就升一档。随机策略在独立政策随机数 < 0.25 时才升。
- 极低现金：终局现金 < 该难度起步现金的 10%。
- 破产：年内最低现金 <= 0。
- 容量卡住：当周占用 >= 容量 95%，且现金够买一件当前在售、但剩余空间放不下的商品。组比率是这种周数 >= 4 的局占比。
- 事件周涨跌：visible 头条 id 不是 move。第 1 周没有涨跌。
- 钳制：H.prices 里 raw !== clamped 才计一次。贴着 min 或 max 且 raw 仍在界内不算钳制。钩子不回写价格。
- 钩子里的事件开始周：价格钩子里的 eventStarted 表示有活跃事件在本周开始。prices 在写新闻之前运行，所以这不是头条分类。
- 保守：在售，且 role 为 daily 或 lowRef，且 price/base < 0.92。仓位 0.4。卖出收益 >= 0.08，或价格/参考价 >= 1.03，或收益 < -0.18。
- 随机：卖出概率 0.5，买入概率 0.5，仓位 0.2 到 0.8。H.seed("policy:"+seed+":"+strategy)，不碰引擎四个随机流。
- 追涨：周涨幅 > 1.025 且价格/参考价 < 1.55，仓位 0.8。卖出：价格 < 上期 × 0.985，或收益 >= 0.2，或收益 < -0.15。
- 价值：价格/参考价 < 0.84，仓位 0.8。卖出收益 >= 0.18，或价格/参考价 >= 1.03，或收益 < -0.3。未上架时，卖出能腾出空间、并且 channelNet 加现有现金够买那件被挡住的折价商品的最少数量。同一周按卖出后的新 visible 再比较。
- 事件感知：缺货或退出持仓卖出。新闻 changeBps <= -800 也卖。收益 < -0.12 也卖。买入本周 fresh 新闻且 changeBps >= 800 的在售商品，仓位 0.6。
- 不交易：不买卖商品。共同住房规则仍然生效。
- 种子：prefix-0 到 prefix-(n-1)，同一序号跨策略配对。本轮不使用留出种子。

## 结论性风险

这些是脚本策略的风险，不是玩家胜率，也不构成自动改价。

- 标准价值买房率主样本 38.9%、留出 41.2%。同难度的保守、随机、追涨、事件感知和不交易都远低于此。价值不是全面可玩的证明。
- 标准价值的 watch/collectible/phone 合份额主样本 41.6%、留出 42.3%，达到 40% 预警。不因此自动削事件。
- 标准保守升级率 100%，仓储档没有留在 room。主样本容量卡住率 87.1%，留出 87.0%。这是共同升级规则下的卡住，不是降仓储价的依据。
- C1 的无租仓对照没有普遍改善。有的组更早买房但利润下降，有的组买房率不升。正式两集没有再跑无租仓。
- 正式 MD 参数段里的「同一难度 30 条价格路径」是冻结脚本旧模板的错误句子。两集 JSON 与涨跌分位 n 按 1000 条路径计算，不按 30。`bankrupt` 在模板里写成破产，实际是现金耗尽，包括买房后现金为 0，不是资不抵债。这些说明只写在本文件和 `docs/gameplay-release-review.md`。没有改 `simulation/c1.cjs`，也没有改两集原始 JSON/MD。
